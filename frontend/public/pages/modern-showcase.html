Animation Features

  • Parallax Scroll: Elements shift based on scroll position
  • Reveal on Scroll: Elements fade in as they enter viewport
  • Belt Accent: Rotating circular decorative elements
  • Neon Glow: Dynamic glow effects on hover
  • Pop-In: Spring-loaded entrance animations
  • Staggered Delays: Sequential animations for lists

Quick Implementation

Using Modern Cards

<div class="modern-card"> <h3>Title</h3> <p>Description</p> <button class="btn-warm">Action</button> </div>

Scroll Animations

<div data-scroll class="reveal-on-scroll"> This will fade in when scrolled into view </div> <div data-parallax class="parallax"> This will move with parallax effect </div>

Counter Animation

<div data-counter="100">0</div> // Initialize in JavaScript: new CounterAnimation();
